# 编辑手册：每天出一期

阅读台每天出一期：从候选池里选 5 篇（最少 3 篇，最多 6 篇），每篇写成中文拆解。所有读者看到的是同一份精选，只有“对你有用”这一段按读者选的方向显示不同版本。

## 步骤

1. `python3 pipeline/fetch.py`（读者想看某个主题的论文时，加 `--paper "主题"`）
2. 读 `pipeline/out/candidates.json`，先看标题和来源筛掉明显不合格的，再**读完全文**，最后定 5 篇。
3. 写 `editions/<今天日期>.json`，格式见下。`no` 取上一期加 1。
4. `python3 pipeline/validate.py`：校验格式、查重、重建 `editions/index.json`。不通过就改到通过为止。
5. 只提交 `editions/`：`git add editions && git commit -m "第 N 期：<5 个短标题>" && git push`。

## 选稿标准

参考 The Browser 的做法：看得多，推得少，每篇都说清为什么值得花时间。

1. **一个月后还值得读。** 常青的分析优先于当天新闻。纯新闻、融资快讯、榜单、活动预告、产品发布稿一律不选。
2. **读者能拿走东西**：一个框架、一组数据、一个可以照做的做法。
3. **原创分析或一手资料**，不选转述；中文转述稿只有在原始材料拿不到时才用，并在“局限”里写明。
4. **正文要看得到。** 付费墙挡住、只能看到开头的，不选，因为没法替读者拆。
5. **跟着读者正在做的事选，而不是只看栏目。** 第 1 期的数据：种子读者点开的三篇都连着她手头的工作（内容增长、写 BP、研究 Jev），只是“栏目对”的三篇都没点开。
6. 宁缺毋滥。某个方向本期没有好稿就空着，不凑数。

种子读者最近在做：研究 BP 和创业方向；跟踪 AI 模型和 AI 产品怎么落地（近期在研究 Jev）；寻找副业方向。在满足标准的前提下，每期至少一半的文章要能直接帮到这三件事。

## 方向标签（tags）

每篇标 1–3 个，只从下面选；`useful` 里给每个标签各写一段。

| key | 显示名 | 说明 |
|---|---|---|
| startup | 创业与商业 | BP、商业模式、GTM、招股书与财报、竞争策略 |
| ai | AI 与技术 | 模型、AI 产品、工程实践、论文 |
| brand | 品牌与营销 | 广告案例、内容增长、品牌建设 |
| money | 金融与经济 | 金融市场、宏观、经济学研究 |
| career | 职业与副业 | 技能、职业选择、个人项目和副业 |
| ideas | 社会与思想 | 社会学、心理、文化、长文随笔 |

## 每篇的写法

中文，用自己的话写，不大段引用原文（直接引语每篇最多一句，15 个词以内）。每一句都要具体：给数字、给例子、给做法，不写“值得深思”这类空话。

- `title`：改写成“这篇讲清了什么”，不照搬原题，也不做标题党。
- `why`：一句话说清为什么值得花时间。
- `useful`：按标签分别写“做这件事的人能怎么用”，具体到场景和动作。
- `points`：核心拆解 3–5 条，每条先给结论，再给依据。
- `takeaway`：1–3 条可以直接拿走的框架、数字或做法。
- `caveat`：作者立场、样本、证据强度、还有哪些不知道的，以及这篇在哪种情况下不适用。
- `minutes`：原文阅读时长（整数，单位分钟），播客按时长算，并在 `media` 写 `"podcast"`。

## 格式

```json
{
  "no": 2,
  "date": "2026-09-25",
  "scanned": 158,
  "sources": 33,
  "note": "这期选了什么、没选什么、为什么（两三句）",
  "articles": [
    {
      "id": "2026-09-25-1",
      "tags": ["startup", "brand"],
      "title": "…", "orig": "原题", "source": "媒体名", "author": "作者",
      "date": "2026-09-21", "url": "https://…", "minutes": 8, "media": "article",
      "why": "…",
      "useful": {"startup": "…", "brand": "…"},
      "points": ["…"], "takeaway": ["…"], "caveat": "…"
    }
  ]
}
```
